# Simulating Fault Detection in Large Scale Bifacial Photovoltaic System

Interactive dashboard for detecting faults in utility-scale bifacial PV farms using:

- PV Farm Power Modelling
- Multi-Area Fault Simulation
- RoCoP (Rate of Change of Power)
- Real-Time Dashboard Visualization
- Interactive Plotly Analytics

---

## Features

✅ 3 PV Farm Zones (A, B, C)  
✅ Single / Double / Full Fault Simulation  
✅ No Fault Scenario  
✅ RoCoP Threshold Detection  
✅ Plotly Interactive Charts  
✅ Export CSV Data  

---

## Technologies Used

- Python
- Streamlit
- Plotly
- NumPy
- Pandas
